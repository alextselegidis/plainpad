# Write, pin and find a note

## Log in

Enter "admin@example.org" as the email and "12345678" as the password, then click "Login".
Verify the notes page opens with "Welcome!" and "Select a note or create a new one."

## Write a note

Click "New Note" in the left sidebar.
In the note editor, type "Groceries" on the first line, press Enter, and type "Milk, eggs and bread".
Verify the note list in the sidebar contains "Groceries".

## Pin it

Click the document icon at the far right of the top bar to open the note panel on the right, and verify a "Pin" button is visible in it.
Click "Pin" and verify the button now reads "Unpin".

## Find it again

Click "New Note" again and type "Weekend plans" on the first line.
In the sidebar filter box, type "Groceries" and verify the list shows "Groceries" but not "Weekend plans".
